# Checklist de Auditoria de Conversão (CRO)

## 1. Primeiros 5 Segundos (Acima da Dobra / Above the Fold)
- [ ] O título responde com clareza: *O que é?* e *Qual dor resolve?*
- [ ] Há um subtítulo explicando o mecanismo ou benefício chave sem jargões corporativos ocos.
- [ ] O Call to Action (CTA) principal é um botão sólido destacado, com contraste visual AA.
- [ ] Há uma prévia visual autêntica da interface do sistema (Bento Grid / PDV em ação).

---

## 2. Redução de Fricção no Cadastro
- [ ] O formulário de teste solicita apenas os dados vitais iniciais (Nome, WhatsApp, Senha).
- [ ] O preenchimento de endereço utiliza consulta automática via CEP.
- [ ] Indicador claro de segurança e privacidade em conformidade com a LGPD.

---

## 3. Matriz de Comparação de Preços
- [ ] O plano recomendado possui destaque visual com badge institucional.
- [ ] Os recursos são comparados por funcionalidade real (ex: *Lotes PEPS/FIFO*, *Emissão NFC-e*, *Relatório DRE*), não por adjetivos vagos.
- [ ] Ausência de taxas ocultas ou termos ambíguos.
