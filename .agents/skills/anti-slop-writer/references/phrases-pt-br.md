# Catálogo de Vícios Textuais em Português (Chatgptês & Jargões Corporativos)

Este catálogo documenta os clichês mais comuns gerados por LLMs em língua portuguesa (PT-BR) e suas alternativas diretas.

---

## 1. Aberturas e Falsas Prestezas (Throat-Clearing)
Modelos de IA adoram anunciar que vão responder antes de realmente responder. Elimine 100% dessas frases.

| Expressão de IA | Ação / Substituição |
| :--- | :--- |
| *"Certamente! Vamos explorar..."* | Corte total. Comece direto no assunto. |
| *"Com certeza, posso te ajudar com isso."* | Corte total. |
| *"É importante destacar que..."* | Corte a expressão. Inicie a frase pelo fato. |
| *"Vale ressaltar / Vale salientar que..."* | Corte a expressão. |
| *"Cumpre assinalar que..."* | Pedantismo desnecessário. Corte. |
| *"Nesse cenário dinâmico e desafiador..."* | Clichê corporativo. Vá direto ao dado ou contexto real. |
| *"No mundo de hoje / Na era digital..."* | Truísmo genérico. Corte. |

---

## 2. Transições Amaciadas e Vícios Conectivos
Transições mecânicas que a IA usa para costurar parágrafos sem adicionar informação:

| Conector Vicioso | Tratamento |
| :--- | :--- |
| *"Diante disso,"* / *"Nesse sentido,"* | Substitua por ponto e vírgula, conectivo preciso (*"Portanto,"*, *"Assim,"*) ou corte. |
| *"Não obstante,"* / *"Outrossim,"* | Arcaísmos forçados. Use *"Contudo"* ou corte se o contraste já for evidente. |
| *"Por um lado... Por outro lado..."* | Troque por análise direta dos dados. |
| *"Uma rica tapeçaria de..."* | Tradução literal cafona de *"rich tapestry"*. Proibido. |

---

## 3. Adjetivos Vazios e Auto-Elogios Inflados
LLMs tendem a qualificar qualquer código, decisão ou documento como genial, elegante ou infalível.

| Palavra Proibida sem Evidência Numérica | Motivo | O que usar no lugar |
| :--- | :--- | :--- |
| *"Robusto"* / *"Robustez"* | A palavra mais batida de IA | Cite as tolerâncias, testes ou exceções tratadas. |
| *"Inovador"* / *"Revolucionário"* | Jargão de relações públicas | Descreva o mecanismo técnico sem bajulação. |
| *"Crucial"* / *"Essencial"* / *"Fundamental"* | Hipérbole | Demonstre a dependência técnica sem adjetivar. |
| *"Perfeito"* / *"Impecável"* | Falsa promessa | Diga que o teste passou com 100% de sucesso. |
| *"Elegante"* / *"Sofisticado"* | Juízo estético subjetivo | Diga que o código segue o princípio da responsabilidade única. |

## 4. Jargões de LinkedIn e Corporativismo Oco

| Jargão de IA / Corporativo | Equivalente Claro e Humano |
| :--- | :--- |
| *"Navegar pelos desafios"* | Resolver os problemas / Tratar as falhas |
| *"Mergulho profundo (deep dive)"* | Análise detalhada / Auditoria minuciosa |
| *"Alavancar resultados"* | Aumentar as vendas / Melhorar os índices |
| *"Virada de chave (game changer)"* | Mudança de estratégia / Novo parâmetro |
| *"Estar na mesma página"* | Ter consenso / Alinhamento prévio |
| *"Desdobrar (unpack) a questão"* | Explicar o funcionamento |
| *"Avançando (moving forward)"* | A partir de agora / Em seguida |
