# Catalog of Toxic English Patterns (Throat-Clearing & AI Tells)

This catalog details formulaic phrasing, emphasis crutches, and business jargon common to English LLM output.

---

## 1. Throat-Clearing Openers
Announcement phrases that delay the point. Delete them and start with the core fact.

- *"Here's the thing:"*
- *"Here's what nobody tells you:"*
- *"It turns out that..."*
- *"The truth is,"*
- *"Let me be clear:"*
- *"Can we talk about..."*
- *"Here's why that matters:"*
- *"The uncomfortable reality is..."*

---

## 2. Emphasis Crutches
Empty intensity words that weaken credibility.

- *"Full stop." / "Period."*
- *"Let that sink in."*
- *"Make no mistake:"*
- *"This is truly transformative."*
- *"Genuinely game-changing."*

---

## 3. Business Jargon Replacements

| Avoid | Use Instead |
| :--- | :--- |
| Navigate (challenges) | Address, solve, handle |
| Unpack (an idea) | Explain, analyze |
| Lean into | Adopt, accept |
| Landscape (context) | Industry, market, situation |
| Game-changer | Significant change, improvement |
| Double down on | Commit more resources to, prioritize |
| Deep dive | Examination, detailed audit |
| Circle back | Return to, discuss later |
| Moving forward | Next, from now on |
| Synergies | Cost savings, combined advantages |

---

## 4. Adverb Purge
Kill filler adverbs ending in `-ly` that act as hedges or artificial intensifiers:
- *"really"*, *"literally"*, *"genuinely"*, *"honestly"*, *"essentially"*, *"fundamentally"*, *"obviously"*, *"seamlessly"*.
